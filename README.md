# 📊 Bellabeat User Activity Analysis

## 🧩 Project Overview
This project explores smart device usage data to uncover behavioral patterns in daily activity.  
The objective was to analyze user movement trends and generate actionable insights that could support business decision-making for a wellness-focused company.

This case study was completed as part of the **Google Data Analytics Professional Certificate**.

---

## 🎯 Business Task
Analyze daily activity data to:

- Understand user activity levels  
- Compare weekday vs weekend behavior  
- Evaluate sedentary patterns  
- Examine the relationship between steps and calorie expenditure  
- Provide strategic recommendations  

---

## 📁 Data Source
Fitbit Fitness Tracker dataset  
(Google Data Analytics Capstone)

---

## 🛠 Tools Used
- Microsoft Excel  
- Pivot Tables  
- Calculated Fields  
- Scatter Plot Analysis  
- KPI Dashboard Design  

---

## 🧹 Data Preparation & Cleaning
- Standardized date formats  
- Removed duplicate records  
- Validated inconsistent entries  
- Aggregated user-level metrics for analysis  

---


## 📈 Key Insights
- Average daily steps: ~6,561  
- Average sedentary time: ~996 minutes  
- Activity patterns remain consistent across weekdays and weekends  
- Calorie expenditure is influenced more by activity intensity than step count alone  

---

## 💡 Recommendations
- Encourage short bursts of moderate-to-high intensity movement  
- Implement strategies to reduce prolonged sedentary time  
- Focus on habit-based engagement rather than weekend-only campaigns  
- Highlight intensity metrics alongside step counts
